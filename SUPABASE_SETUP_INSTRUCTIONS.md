# Инструкция по настройке Supabase

## Проблема
Кнопка "Создать карту" в дашборде не работает, и данные не поступают в Supabase таблицы.

## Решение

### 1. Выполните SQL скрипт в Supabase Dashboard

1. Откройте ваш проект в [Supabase Dashboard](https://supabase.com/dashboard)
2. Перейдите в раздел **SQL Editor**
3. Скопируйте содержимое файла `supabase_setup.sql` и вставьте в редактор
4. Нажмите **Run** для выполнения всех команд

### 2. Проверьте созданные таблицы

После выполнения скрипта проверьте, что созданы следующие таблицы:
- `card_templates` 
- `issued_cards`

И storage buckets:
- `card-logos`
- `card-covers`

### 3. Проверьте аутентификацию

Убедитесь, что пользователь залогинен:
1. Откройте DevTools в браузере (F12)
2. Перейдите на вкладку **Console**
3. Попробуйте создать карту
4. Проверьте логи в консоли - там будет отладочная информация

### 4. Возможные проблемы

#### Проблема с RLS (Row Level Security)
Если данные все еще не сохраняются, временно отключите RLS для тестирования:

```sql
-- В SQL Editor выполните:
ALTER TABLE card_templates DISABLE ROW LEVEL SECURITY;
ALTER TABLE issued_cards DISABLE ROW LEVEL SECURITY;
```

После тестирования включите обратно:
```sql
ALTER TABLE card_templates ENABLE ROW LEVEL SECURITY;
ALTER TABLE issued_cards ENABLE ROW LEVEL SECURITY;
```

#### Проблема с Storage
Если файлы не загружаются, проверьте:
1. Созданы ли storage buckets
2. Правильные ли политики для storage

### 5. Отладка

В коде добавлена подробная отладочная информация. При создании карты в консоли браузера вы увидите:
- Данные пользователя
- Процесс загрузки файлов
- Данные для вставки в базу
- Результат операции

### 6. Проверка работы

После настройки:
1. Создайте тестовую карту
2. Проверьте, что она появилась в списке карт
3. Проверьте таблицы в Supabase Dashboard

Если проблемы остаются, проверьте логи в консоли браузера и сообщите об ошибках.
