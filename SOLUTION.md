# Решение проблемы с созданием карт в Dashboard

## Проблема
Кнопка "Создать карту" в дашборде не работает, таблицы в Supabase не функционируют.

## Причины
1. **Отсутствует зависимость `@supabase/supabase-js`** - основная причина
2. **Неправильные политики storage** в Supabase
3. **Возможные проблемы с RLS** (Row Level Security)

## Решение

### 1. Установка зависимостей ✅
```bash
cd frontend
npm install @supabase/supabase-js
```

### 2. Обновление SQL скрипта ✅
Файл `supabase_setup.sql` обновлен с исправленными политиками storage.

### 3. Выполнение SQL скрипта в Supabase
1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое `supabase_setup.sql`
4. Выполните все команды

### 4. Тестирование подключения
Откройте `frontend/test-supabase.html` в браузере для проверки подключения к базе.

### 5. Проверка в приложении
1. Запустите приложение: `npm run dev`
2. Войдите в систему
3. Попробуйте создать карту
4. Проверьте консоль браузера (F12) на ошибки

## Возможные дополнительные проблемы

### RLS блокирует доступ
Если данные все еще не сохраняются, временно отключите RLS:
```sql
ALTER TABLE card_templates DISABLE ROW LEVEL SECURITY;
ALTER TABLE issued_cards DISABLE ROW LEVEL SECURITY;
```

### Storage не работает
Проверьте:
1. Созданы ли buckets `card-logos` и `card-covers`
2. Правильные ли политики для storage
3. Есть ли права на загрузку файлов

## Проверка работы

После выполнения всех шагов:
1. Создайте тестовую карту
2. Проверьте, что она появилась в списке
3. Проверьте таблицы в Supabase Dashboard
4. Проверьте загруженные файлы в Storage
